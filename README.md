<h1 align="center">Stamped.io for Craft CMS</h1>

Stamped.io is a Craft CMS plugin that connects completed Craft Commerce orders to Stamped.io's review workflow. Send the order and customer details Stamped.io needs so review requests can follow the purchase without manual exports.

When an eligible Craft Commerce order reaches the configured state, queue its customer and line-item information for Stamped.io. The store's normal order workflow remains the source of truth.

## Features

- Use completed Craft Commerce purchases as the review source.
- Include purchased line items so requests refer to the right products.
- Send the recipient information required for the follow-up.
- Process the Stamped request through background work.
- Hand eligible purchases to Stamped.io for customer review requests.
- Keep the Stamped connection and behaviour in project settings.
